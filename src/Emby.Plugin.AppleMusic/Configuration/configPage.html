国家 / 地区

Apple 会按服务器出口 IP 做地理跳转，网页数据源实际能用的区域有限，国内一般保持 cn。

专辑数据走 iTunes API，这个区域不受 IP 跳转影响，jp 区返回原始假名的艺人名与曲目名。

Apple 只给少数艺人配简介，网易云补中文简介；也用于艺人头像回退与别名匹配。
